# DeepSeek V4 Pro for AI Notes

The AI Note attached to each Sighting is generated by `deepseek-v4-pro` over DeepSeek's OpenAI-compatible endpoint (`POST https://api.deepseek.com/chat/completions`), not by a Claude model.

The Note is a one- or two-sentence reading of a Word in one Sighting's sentence, generated once per capture. At roughly 300 input and 60 output tokens, DeepSeek costs about $0.0002 per Note against about $0.003 on `claude-opus-5` — a thousand captured Words is $0.18 rather than $3. The task is small and well-bounded, so the quality difference does not justify a 17x cost multiple on a personal tool. The prompt is deliberately ordered instructions-first so the fixed block hits DeepSeek's context cache, which prices cached input roughly 120x below a cache miss.

Because the endpoint is OpenAI-compatible, moving to another provider is a base-URL and model-string change rather than a rewrite — the lock-in is small. DeepSeek's documentation warns of a significant price increase, which is the most likely reason to revisit this.
